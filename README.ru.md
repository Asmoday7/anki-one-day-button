# HoldUp - Отправь карточку и в FSRS, и отдельную очередь!

[English](README.md) · **Русский**

Не уверены, что запомнили карточку? **HoldUp** позволяет увидеть её ещё раз
в выбранное время, дополнительно к обычным повторениям Anki.

**[Скачать 0.4.2-dev](https://github.com/Asmoday7/holdup-anki-addon/raw/refs/heads/main/dist/holdup-0.4.2-dev.ankiaddon)**

[Инструкция пользователя](USER_GUIDE.ru.md) · [User guide](USER_GUIDE.md)

## Установка

Если уже установлена другая копия этого аддона, отключите её через
**Инструменты → Дополнения** и перезапустите Anki. Затем установите скачанный
архив через **Инструменты → Дополнения → Установить из файла** и снова перезапустите Anki.

Существующие карточки и назначения практики остаются в коллекции. При необходимости
выберите интервал заново: локальные настройки другой установки автоматически
не копируются. Оставьте включённой только одну копию.

Python отдельно устанавливать не нужно. Первую проверку проведите в тестовом профиле.

## Как работает

1. Покажите ответ и нажмите **HoldUp**. Галочка подтвердит дополнительное
   назначение. Ответ оригинала остаётся открытым.
2. Выберите **Снова / Трудно / Хорошо / Легко** для оригинала. Это обычная оценка
   Anki: она учитывается FSRS и расходует дневной лимит новых карточек.
3. Практика сохраняет собственный срок независимо от этой оценки. Например,
   Good назначил оригинал через восемь дней, а практика будет готова через две минуты.
4. Готовая практика появляется между карточками в том же окне изучения с подписью
   **«HoldUp · практика без оценки FSRS»**.
5. **«Ещё через…»** назначает следующий дополнительный показ, **«Готово»** завершает
   практику этой карточки. Эти действия не записывают оценок FSRS.

Одна карточка может иметь одно дополнительное назначение. Повторное назначение
заменяет его срок. Физическая копия карточки или заметки не создаётся. Само нажатие
HoldUp не ставит Good и не расходует дневной лимит: это делает обычная оценка.

## Язык и время

Язык выбирается по настройкам Anki: русский для русского интерфейса, английский
для остальных языков. Оба перевода включены в пакет. После смены языка перезапустите Anki.

Интервал задаётся через **⋯** или **Инструменты → HoldUp: интервал…**.
Есть пресеты 2 секунды, 2 минуты, 1 час, 1 день и ввод от 1 до 86400 секунд.

- **«1 день»** — ровно 24 часа после нажатия.
- **«Следующий учебный день Anki»** — ближайшее начало дня из настроек Anki.
  При начале в 04:00 нажатие в 23:00 или 02:00 назначит ближайшие 04:00.
  Границу вычисляет Anki с учётом местного времени и переходов времени.

Настройки действуют на следующие нажатия. Уже назначенные сроки остаются
конкретными датами, даже если изменить начало дня в Anki.

## Очередь и индикаторы

В изучении зелёное число включает готовую практику; подсказка показывает доли
Anki и HoldUp. Синий и красный счётчики берутся из Anki. Пассивная подпись
**«HoldUp: ожидают N»** показывает будущие дополнительные назначения.

На странице **«Колоды»** зелёная метка с часами **«HoldUp · N»** показывает готовую
практику, даже когда три штатных числа равны нулю. Для начала нажмите название
колоды. Родитель включает подколоды, в том числе свёрнутые; их числа перекрываются.
Будущие и недоступные назначения не создают метку готовности.

Практика берётся из выбранной колоды и подколод. Срок означает минимальную
готовность: текущий ответ и более ранние сроки Anki могут задержать показ.
При закрытой Anki назначения ждут следующего сеанса. Действие **«Продолжить изучение»**
на странице колоды возвращает в тот же reviewer, когда практика готова.

Назначение, повтор, завершение и очистка поддерживают **Undo/Redo**.
После **HoldUp → обычная оценка → Undo** отменяется только обычная оценка:
оригинал возвращается, а срок HoldUp сохраняется. Следующий Undo отменит предыдущее
назначение HoldUp, если между ними не было другого действия с коллекцией.
Отмена повтора практики или **«Готово»** затрагивает только назначение практики.
**Инструменты → HoldUp: убрать всю практику** удаляет дополнительные назначения
открытой коллекции, включая будущие. Карточки и обычные оценки сохраняются.

## Разработка

У runtime нет зависимостей сверх Anki. Исходники находятся в [`holdup/`](holdup/),
а [`i18n.py`](holdup/i18n.py) содержит английские строки и русский перевод.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-dev.txt
python -m pytest -m "not anki_contract and not anki_gui" --basetemp=.dev/pytest-unit
```

Для backend установите `requirements-anki.txt`. Для desktop-проверок используйте
отдельные окружения с `requirements-gui-26.09.txt` или `requirements-gui.txt`.
Не устанавливайте обе версии Anki в одно окружение. GUI-прогоны запускайте
последовательно из-за single-instance механизма Anki.

```bash
python -m pytest --basetemp=.dev/pytest-full
python tools/package_addon.py
```

Сборка — `.dev/dist/holdup.ankiaddon`. Архивы и контрольные суммы — в [dist](dist/README.md).
Тесты используют временные коллекции и профили без AnkiWeb. Pytest очищает
`--basetemp`: не храните там личные данные. Пропущенные backend/GUI-проверки
не подтверждают интеграцию.

[Архитектура](ARCHITECTURE.md) · [Ручная проверка](TESTING.md).
Windows/Python 3.13, реальная синхронизация, аудио и сложные шаблоны требуют
ручной проверки. AnkiDroid не запускает Python-аддоны настольной Anki.
Практика не передаёт оценок в FSRS, хотя может повлиять на память человека
и его следующие обычные ответы.

Проверено на Linux: **167 passed** на каждой из Anki **26.09 (e62e7739)** и
**26.09.3 (29bb700b)**, включая русский/английский GUI с минутными шагами и без них.
Windows и синхронизация между устройствами требуют ручной проверки.
